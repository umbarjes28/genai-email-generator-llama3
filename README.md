# 🚀 End-to-End GenAI Email Generator | LLaMA 3.1 + LangChain + ChromaDB

A fully integrated GenAI application that generates professional cold emails from job descriptions using LLaMA 3.1. The app leverages LangChain, ChromaDB, and Streamlit to deliver intelligent and contextualized email outputs.
---

## 🧠 Tech Stack

- 🦙 LLaMA 3.1 (via Groq API)
- 🦜 LangChain
- 🧠 ChromaDB (Vector Store)
- 🐍 Python
- ⚙️ Prompt Engineering
- 📦 UUID, Pandas, Requests, FastAPI (optional)

---

## 🎯 Features

✅ LLaMA 3.1 powered generation

✅ Cold email personalization using job description + portfolio match

✅ Vector database integration using ChromaDB

✅ Streamlit UI for real-time generation

✅ Modular and production-ready code

## 🛠️ Setup Instructions

1. Clone the repo:
   ```bash
   git clone https://github.com/umbarjes28/genai-email-generator-llama3.git
   cd genai-email-generator-llama3
   
2. Create and activate your virtual environment:
    ```bash
    conda create -n genai python=3.10
    conda activate genai

3. Install dependencies:
    ```bash
    pip install -r requirements.txt

4. Run the app
    ```bash
    streamlit run app.py
